# 01-api-tiendanube — Documentación Técnica Completa

Bienvenido al módulo completo de automatización de inventario. A continuación tienes el código fuente estructurado para conectar el catálogo mayorista con tu tienda online mediante webhooks: 

import requests

def sync_inventory(store_id, token, supplier_stock):
    headers = {"Authentication": f"bearer {token}", "User-Agent": "HubSync/1.0"}
    for sku, qty in supplier_stock.items():
        payload = {"stock": qty, "published": qty > 0}
        requests.put(f"https://api.tiendanube.com/v1/{store_id}/products/{sku}", json=payload, headers=headers)
    return "Sincronización completada con éxito."

Instrucción de despliegue: Sube este script a un entorno serverless o cron-job cada 30 minutos para evitar ventas sin stock físico.
